# Übung 1: REST-Schnittstelle automatisiert testen

Lazar & Dominik, Modul 450

Die REST-Schnittstelle des Backends wird mit REST Assured getestet.

## Ausführen

Es muss nichts laufen, der Test startet den Server selber.

```bash
cd spring-boot-angular-basic-lw2
mvn test
```

Ergebnis: 16 Tests, 0 Fehler, 3 übersprungen.
